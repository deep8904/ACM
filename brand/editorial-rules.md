# Editorial Rules

## Always

- Prefer primary sources.
- Link claims to evidence.
- Separate reporting, analysis, and opinion.
- Include meaningful limitations.
- Correct errors visibly when discovered.
- Disclose whether product coverage is hands-on.
- Use exact dates when timing matters.
- Preserve uncertainty.
- Explain reader impact.
- Maintain a record of sources.

## Never

- Invent facts, quotes, prices, tests, or experience.
- Present rumors as confirmed.
- Copy another article's wording or structure.
- Hide sponsorship or affiliate relationships.
- Use a misleading headline.
- Publish solely to meet a quota.
- Generate outrage for attention.
- Use fake urgency.
- Attack individuals.
- Treat community comments as representative evidence without qualification.

## Publication threshold

An article should publish only when it offers at least one of:

- Clear explanation that is missing from existing coverage.
- Useful technical synthesis.
- Practical buying guidance.
- Context connecting the event to broader industry changes.
- A well-supported original viewpoint.
- A concise reference readers will continue using.

## Corrections

When a material error is found:

1. Correct the article.
2. Update the `updatedAt` field.
3. Add a correction note when the error affected interpretation.
4. Preserve the reason in the publication log.
5. Update social posts when practical.

## AI disclosure

The publication does not need to describe every editing tool used, but it must not misrepresent testing, reporting, interviews, or first-hand experience. If AI assistance materially affects a sensitive or research-heavy article, consider a brief methodology note.
